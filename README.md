# TXT 格式处理工具

五个功能：

- **格式映射**：按自定义规则对单个 txt 做段的保留 / 删除 / 调换
- **格式添加**：两个 txt 按行用 `----` 整行拼接（先上传的在前）
- **别名随机**：第 1 段邮箱在 `@` 前加 `+`、可选指定串、再接随机（首位字母，其余字母+数字）
- **提取数据**：从开头提取 N 条有效行；每提一行立刻写入输出并从原文件删除
- **文件去重**：两文件整行集合对比；输出相同行，以及两边独有整合

## 首次使用

1. 本机安装 Python 3.10+（安装时勾选 Add to PATH）
2. 进入项目目录，双击 `build_exe.bat`，等待生成 `dist\FormatTool.exe`
3. 打开 exe，顶部切换功能页

### 格式映射

1. 选择 txt，填总段数并点「生成映射框」
2. 上面是原段序号，下面填映射：数字表示取原第几段，`0` 表示丢掉
3. 点「开始处理」，结果保存在源文件同目录（文件名带时间戳）

示例（原行 7 段）：

- `1 5 0 0 0 0 0` → 只保留第 1、5 段
- `1 3 0 0 0 6 7` → 保留第 1、3、6、7 段

注意：全是 `0` 或填了超出范围的数字会报错；段数对不上的行、空行会跳过。

### 格式添加

1. 先后选择两个 txt
2. 跳过空行后，按行拼接成：`先文件整行----后文件整行`
3. 行少的一侧用完即停
4. 结果写到 exe 同目录：`merged_时间戳.txt`
5. 有剩余则另存 `剩余_原文件名_时间戳.txt`；无剩余则提示无剩余

### 别名随机

1. 选择 txt
2. 填随机位数：默认 `4` `-` `6`；都空也当 4～6；只填一边或两边相同则为固定位数；左大于右则对调；不能填 `0`
3. 指定随机可空；有内容则原样接在 `+` 后面，再接随机（指定不计入位数）
4. 随机串首位必须是小写字母，其余为小写字母 + 数字混合；无 `@` 或空行跳过
5. 结果写到 exe 同目录：`alias_时间戳.txt`

例：指定 `vip`、位数 4～6 → `frank@hotmail.com----其它` → `frank+vipab3x@hotmail.com----其它`

### 提取数据

1. 选择 txt（会改写原文件）
2. 填写要提取的有效行数 N
3. 从开头往后：空行只删不写；有效行写入输出后立刻从原文件删除
4. 凑满 N 条或原文件提空为止；提空后原文件保留为空文件
5. 结果写到 exe 同目录：`提取N行_时间戳.txt`

### 文件去重

1. 选择两个 txt
2. 按整行内容做集合对比（忽略空行；同一文件内重复只算一次）
3. 写出两边都有的行 → `相同行_时间戳.txt`（只留一份）
4. 写出仅在一边出现的行合到一起 → `独有行_时间戳.txt`（各留一次）
5. 结果在 exe 同目录；重名覆盖；结果行顺序不保证
